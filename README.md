# Study Tracker (Node.js CLI Application)

A simple command-line Study Tracker that allows a learner to record study sessions, list them, and view total minutes studied. This project was built using Node.js and focuses on clean input handling, validation, and incremental development supported by a GitHub Project Board.

---

## Features

- Add a study session with:
  - A non-empty topic  
  - A duration in whole minutes greater than zero  
- List all recorded study sessions  
- Display the total minutes studied  
- Reject invalid input with clear error messages  
- Simple text-based menu for navigation  
- Clean exit behaviour
